# Vibe Coding Studio

A small, single-page writing space for jotting down an idea and taking it to an AI service you already use.

## Use it

Open `index.html` in a modern browser. No installation, account, API key, or setup is needed.

- Write or paste plain text in the editor.
- Select **Copy** to copy your note, or **Save** to download it as `vibe-note.txt`.
- Open ChatGPT, Claude, or Gemini from the links at the top, then paste your note there if you want AI help.

Text stays in the current page session. It is not automatically saved; download anything you want to keep. The editor does not connect to AI services or send your text anywhere.
