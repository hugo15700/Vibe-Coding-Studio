A little note before you begin

Welcome to Vibe Coding Studio

This studio was created with Vibe Coding — a reminder that a clear idea, a little curiosity, and the right tools can take you a long way. Now it's your turn to make something.

A few good habits
  • Keep secrets private. Never paste passwords, API keys, or personal information into prompts or code.
  • Review before you run. AI-generated code can be wrong. Read changes and only run code you trust.
  • Back up your work. Save copies of projects you care about; experiments can break things.
  • Check what you share. Be thoughtful about permissions, external links, and where your code or data goes.
Good to know: This is a lightweight studio demo. Project files stay in this page and are not saved to a server. To use the assistant, connect an OpenAI-compatible API in its Setup tab. Your API key stays in page memory only; prompts go directly to your chosen provider.
